# Legacy UART/APB Verification Files

## English

This directory preserves APB checkers, UART/APB sequence patterns and old Questa scripts found in the repository. They are unrelated to the three AES RTL variants and are not invoked by the AES Makefile.

## Tiếng Việt

Thư mục này giữ checker APB, sequence pattern UART/APB và script Questa cũ tìm thấy trong repository. Các tệp này không thuộc ba AES RTL variant và không được Makefile AES gọi.
