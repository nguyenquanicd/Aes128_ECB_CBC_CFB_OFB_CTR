# Verification Layout

## English

Verification assets are separated by RTL variant. `single_aes128/`, `ht_aes128/` and `ht_aes128_256/` each hold their testbench, vectors, logs and reports. `shared/` holds the independent AES reference model. `legacy_uart_apb/` preserves unrelated UART/APB files and is not part of the AES flows.

## Tiếng Việt

Tài nguyên verification được chia theo RTL variant. `single_aes128/`, `ht_aes128/` và `ht_aes128_256/` chứa testbench, vector, log và báo cáo của từng nhánh. `shared/` chứa mô hình AES tham chiếu độc lập. `legacy_uart_apb/` giữ các tệp UART/APB không liên quan và không thuộc flow AES.
