# Single-Block AES-128 RTL

## English

Legacy iterative AES-128 implementation. The top module is `aes128`. `filelist.f` uses repository-root-relative paths; compile it from the repository root. Functional and implementation notes are in [the design documentation](../../doc/single_aes128/README.md).

## Tiếng Việt

Đây là implementation AES-128 tuần tự cũ. Module top là `aes128`. `filelist.f` dùng đường dẫn tương đối từ repository root; hãy chạy compiler từ root. Mô tả chức năng và implementation ở [tài liệu design](../../doc/single_aes128/README.md).
