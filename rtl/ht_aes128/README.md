# High-Throughput AES-128 RTL

## English

Pipelined AES-128 batch implementation. The top module is `m_aes128_batch_top`; the ordered source list is `filelist.f`. Filelist entries are relative to this folder. The contract is in the [AES-128 batch specification](../../doc/ht_aes128/AES128_ECB_CBC_CFB_OFB_CTR_Design_Specification.md). Lint and generation reports are under `verification/ht_aes128/reports/`.

## Tiếng Việt

Đây là batch implementation AES-128 có pipeline. Module top là `m_aes128_batch_top`; thứ tự source nằm trong `filelist.f`. Đường dẫn filelist tính từ thư mục này. Hợp đồng thiết kế nằm trong [đặc tả batch AES-128](../../doc/ht_aes128/AES128_ECB_CBC_CFB_OFB_CTR_Design_Specification.md). Báo cáo lint và generate ở `verification/ht_aes128/reports/`.
