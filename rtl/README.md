# RTL Variants

## English

This folder contains exactly three implementation directories: `single_aes128/`, `ht_aes128/`, and `ht_aes128_256/`. Each subfolder contains its own RTL and compile-order filelist. Testbenches and generated logs are kept under `verification/`.

## Tiếng Việt

Thư mục này chỉ chứa ba nhánh implementation: `single_aes128/`, `ht_aes128/` và `ht_aes128_256/`. Mỗi thư mục có RTL và filelist theo thứ tự biên dịch riêng. Testbench và log được lưu trong `verification/`.
