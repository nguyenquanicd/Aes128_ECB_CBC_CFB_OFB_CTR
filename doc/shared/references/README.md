# Shared Standards References

## English

This directory stores the NIST FIPS 197 and SP 800-38A source PDFs, converted Markdown copies and conversion index. The specifications cite these files; use the official NIST editions as the normative source.

## Tiếng Việt

Thư mục này lưu PDF NIST FIPS 197 và SP 800-38A, bản Markdown đã chuyển đổi và file chỉ mục. Các đặc tả trỏ tới những bản này; bản NIST chính thức là nguồn quy phạm.
