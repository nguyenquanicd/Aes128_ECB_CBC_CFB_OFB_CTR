# Shared Documentation

## English

`references/` contains project-local copies of the AES and mode standards used by both batch-core specifications. Design-specific documents and research stay in their corresponding design folders.

## Tiếng Việt

`references/` lưu bản sao trong dự án của tiêu chuẩn AES và các mode được hai đặc tả batch core sử dụng. Tài liệu và nghiên cứu riêng được giữ trong thư mục của từng design.
