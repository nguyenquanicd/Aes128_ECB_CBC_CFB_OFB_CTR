# High-Throughput AES-128/AES-256 Documentation

## English

The [design specification](AES128_AES256_ECB_CBC_CFB_OFB_CTR_Design_Specification.md) defines the dual-key-size batch core. `figures/` contains its architecture diagram and approved timing figures; `research/` records AES-256 reference research. Shared NIST documents are stored in `../shared/references/`.

## Tiếng Việt

[Đặc tả design](AES128_AES256_ECB_CBC_CFB_OFB_CTR_Design_Specification.md) định nghĩa batch core hỗ trợ hai kích thước khóa. `figures/` chứa sơ đồ kiến trúc và waveform đã duyệt; `research/` lưu nghiên cứu tham khảo AES-256. Tài liệu NIST dùng chung nằm trong `../shared/references/`.
