# High-Throughput AES-128 Documentation

## English

The [design specification](AES128_ECB_CBC_CFB_OFB_CTR_Design_Specification.md) defines the AES-128 batch interface and behavior. `figures/` contains the architecture diagram; `waveforms/` contains specification-approved timing examples; `research/` records reference-IP research. NIST source documents shared with the dual-key design are in `../shared/references/`.

## Tiếng Việt

[Đặc tả design](AES128_ECB_CBC_CFB_OFB_CTR_Design_Specification.md) định nghĩa interface batch và hành vi AES-128. `figures/` chứa sơ đồ kiến trúc; `waveforms/` chứa ví dụ timing đã được duyệt; `research/` lưu nghiên cứu IP tham khảo. Tài liệu NIST dùng chung với design hai key size nằm trong `../shared/references/`.
